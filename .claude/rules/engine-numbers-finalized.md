# Engine-Computed Numbers Are Finalized

**Engine-computed numbers are never directly editable by a user, human or
AI, once produced by the deterministic pipeline.** No endpoint, UI control,
or agent action should overwrite a figure the QoE engine, financial
statement builder, NWC analyzer, DCF engine, or red flag detector computed.

Product owner's explicit instruction: *"any number generated by the FDD
engine should be finalized... remove the ability to override numbers."*

An analyst's role, once the in-flight override design (below) is
reconciled with this rule, is limited to:

- **categorical actions** — flag as disputed, request more documentation;
- **additive actions** — attach a manual adjustment the engine never
  proposed, clearly attributed as analyst-added and separate from engine
  output.

Never overwriting a number the pipeline produced.
